## 👨‍💻 About Me

Hi, I'm **Rakshith Nanduri**, a Computer Science student from India working toward becoming an **AI Engineer**.

I learn best by building real software. My repositories range from local-AI applications created with **Python, Streamlit, and Ollama** to command-line systems written in **C** using structures, file handling, searching, sorting, and dynamic memory.

I care more about genuine understanding and steady engineering progress than collecting technologies for a badge wall. Every completed project is another step toward building software that is useful, reliable, and increasingly ambitious.

- 🤖 I enjoy exploring **Artificial Intelligence, local LLMs, and software engineering**.
- 🧩 I like breaking difficult problems into small, understandable parts.
- 🏎️ Away from the terminal, I follow **Formula 1**, gaming, and new technology.
